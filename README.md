# 100 Dias de JavaScript

Um exercício de JavaScript por dia, do zero. Cada dia é uma página HTML independente (`diaN.html`) que se abre e joga no navegador.

A página inicial (`index.html`) lista todos os dias e destaca o mais recente.

## Exercícios

| Dia | Exercício |
|----|-----------|
| 1 | Olá utilizador |
| 2 | Sucessor e Antecessor |
| 3 | Dobro e Triplo |
| 4 | Média |
| 5 | Número positivo |
| 6 | Par ou Ímpar |
| 7 | Maior Número |
| 8 | Idade |
| 9 | Contagem de 1 a 100 |
| 10 | Jogo da Senha |

## Como correr

Abre o `index.html` no navegador, ou usa o Live Server do VS Code.
